# DROPZONE 🎮

**Your Fortnite player hub.**  
Epic Games news, player tools, community discoveries, and useful Fortnite links — all in one place.

## ✨ Features

- 📰 **Fortnite News** — a news section featuring Epic Games announcements, with links to the official Fortnite newsroom.
- 🕵️ **Leaks & Rumours** — a clearly labelled space for unofficial community information.
- ⚡ **XP Map Codes** — save Creative island codes and copy them easily.
- 🛒 **Item Shop** — quick access to the official Fortnite Item Shop.
- 🎟️ **Battle Pass Tracker** — track your current level against a target level.
- 🏆 **Tournament Countdown** — a sample UTC midnight countdown and a link to official competitive information.
- 🔔 **Update & Downtime Preferences** — a checklist for the alerts you want to follow.
- 🟢 **Server Status** — fetches the public Epic Games status API when available.
- 🔎 **News Search & Filters** — find news cards by keyword or category.

## 🚀 Run locally

1. Download or clone this repository.
2. Open `index.html` in a web browser.

No build tools or package installation are required.

## 🌐 Publish with GitHub Pages

1. Open the repository's **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder.
5. Save. GitHub will provide the public website URL after deployment.

Make sure the homepage file is named `index.html`.

## ⚠️ Important notes

- DROPZONE is an **unofficial fan-made project** and is not affiliated with, endorsed by, or sponsored by Epic Games.
- Fortnite, Epic Games, and related names and marks belong to their respective owners.
- News cards included in the current version are sample editorial entries linking to Epic's official newsroom. They are **not a live news feed**.
- The Item Shop link opens Epic's official shop; shop items are not copied into DROPZONE.
- The server status widget uses Epic's public status API. It may not load if the API or browser connection is unavailable.
- The tournament countdown is a sample timer to the next UTC midnight, **not a real tournament start time**.
- Alert preferences are a visual checklist only. This version does not send push notifications.
- XP rewards and Creative island availability can change. DROPZONE does not guarantee XP from any map.
